VOX 🎙️ — Offline AI Meeting Assistant

VOX transcribes meeting audio, generates summaries, and organizes action items — all offline, with no cloud dependency.

Features
🎧 Offline transcription using Vosk ASR (no cloud, no privacy risk)
🧠 Smart summaries with TF-IDF + Sentence-BERT (SBERT)
✅ Automatic extraction of action items, decisions & keywords
📋 Kanban board for task organization
📊 Analytics dashboard & PDF export
🔐 Role-based access control for team collaboration
Tech Stack

Python · Flask · SQLite · Vosk · SBERT · FFmpeg · JavaScript · Chart.js · ReportLab
